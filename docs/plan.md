# System plan

Full plan with diagrams (Claude Doc, live/shareable):
https://claude.ai/code/artifact/7cc4b26d-e436-4471-abf8-5336a9e648a8

## The five pillars
1. **Project Ready** — very_good_cli scaffold + flavors, feature-first clean
   architecture, core abstractions (network, logging, error reporting,
   routing, DI, theming).
2. **Widget Ready** — skill files + subagents that keep AI-generated widgets
   on-convention.
3. **Design Ready** — Figma MCP -> Flutter widget code, mapped to the design
   system.
4. **Testable** — unit/widget/golden/integration tests generated by default,
   coverage gated in CI.
5. **Deployable** — generated CI/CD, signing, and store-deployment pipelines.

## Decided
- State management (Bloc vs Riverpod) stays a per-project interview question,
  not a hard default — needs vary by client. (Resolved 2026-09-30.)

## Build roadmap
Phase 1 core scaffold -> Phase 2 AI skills/subagents -> Phase 3 design +
test integration -> Phase 4 deploy automation -> Phase 5 package as a
plugin, pilot, then team-wide rollout.
